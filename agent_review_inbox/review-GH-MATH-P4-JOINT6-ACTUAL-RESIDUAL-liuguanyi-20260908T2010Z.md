## 2. Minimal rational-residual bridge

Let the actual and contract residuals on the same marker cell `C` be represented by

`R_a(x) = N_a(x) / D_a(x)`,

`R_c(x) = N_c(x) / D_c(x)`.

Assume throughout `x in C` and the denominator regime

`|D_a(x)| >= delta_a > 0`,

`|D_c(x)| >= delta_c > 0`.

Define the **signed cross mismatch**

`Q(x) := N_a(x) D_c(x) - N_c(x) D_a(x)`

and the denominator product

`P(x) := D_a(x) D_c(x)`.

Then the exact identity is

`R_a - R_c = Q / P`.

This is the right source-to-math interface because it forms the correlated signed cancellation **before** any absolute-value enclosure or interval division.

### Theorem A — exact equality by cross multiplication

If

`Q(x) = 0` for every `x in C`,

then

`R_a(x) = R_c(x)` for every `x in C`.

No division is required in the trusted scalar check once denominator nonvanishing has been certified.

### Theorem B — same-cell sup containment

If in addition

`|Q(x)| <= E`

for every `x in C`, then

`|R_a(x)-R_c(x)| <= E/(delta_a delta_c)`.

For a requested rational residual budget `B`, the checker can avoid division entirely and accept the sufficient gate

`E <= B delta_a delta_c`.

Thus a source lane does **not** need to export a floating quotient bound; it needs only a signed cross-mismatch enclosure and exact rational denominator lower bounds.

### Theorem C — same-cell Lipschitz containment

Let

`delta := delta_a delta_c`.

Assume on `C`

`|P| >= delta`,

`|Q| <= E`,

`Lip_C(Q) <= L_Q`,

`Lip_C(P) <= L_P`.

Then for `x,y in C`,

`Q(x)/P(x) - Q(y)/P(y)`

`= [Q(x)-Q(y)]/P(x) + Q(y)[P(y)-P(x)]/[P(x)P(y)]`,

so

`Lip_C(R_a-R_c) <= L_Q/delta + E L_P/delta^2`.

For a requested Lipschitz mismatch budget `L`, a division-free sufficient gate is

`delta L_Q + E L_P <= L delta^2`.

This is the smallest useful bridge if P4 needs not only a pointwise residual budget but a same-cell Lipschitz contract.

## 3. Why the source must cross-multiply before enclosure

A naive adapter that separately bounds `|N_a|`, `|N_c|`, `|D_a|^{-1}`, and `|D_c|^{-1}` destroys cancellations that are exactly relevant to equality of two residual representations.

For example, if the actual and contract CSE differ only by a common algebraic rescaling

`N_a = s N_c`, `D_a = s D_c`

with a nonzero same-cell factor `s`, then

`Q = (sN_c)D_c - N_c(sD_c) = 0`

identically.  Entrywise/absolute-first bounds generally produce a positive fake discrepancy instead.  Hence the preferred source order is

actual signed CSE + contract signed CSE
→ `Q := N_a D_c - N_c D_a`
→ simplify/cancel exactly
→ enclosure of the remaining `Q`
→ division-free gate.

The same principle applies to `P=D_aD_c`: form the product in the known sign/nonvanishing regime first, then certify its lower bound and Lipschitz packet.

## 4. Required source packet to close the principal branch

The remaining source obligation is now small and explicit.  On the exact P4 marker class/cell, provide:

- `actual_num = N_a` and `actual_den = D_a` for the **principal compact joint6 branch**, not the state-library/base-row fallback;
- `contract_num = N_c` and `contract_den = D_c`, or an exact algebraic representation of the existing P4 residual contract;
- exact observable binding showing both residuals refer to the same joint-6 quantity and sign convention;
- exact-rational `delta_a, delta_c > 0` with same-cell proofs `|D_a|>=delta_a`, `|D_c|>=delta_c`;
- preferably the already-simplified signed polynomial/rational CSE for `Q=N_aD_c-N_cD_a`;
- either `Q=0`, or an exact-rational `E` proving `|Q|<=E`;
- if the downstream contract consumes a Lipschitz residual, also `L_Q` and `L_P` with `Lip(Q)<=L_Q`, `Lip(D_aD_c)<=L_P`.

A minimal typed adapter record can therefore be:

`actual_num`, `actual_den`, `contract_num`, `contract_den`,

`actual_den_abs_lower`, `contract_den_abs_lower`,

`cross_mismatch_abs_upper`,

and optionally

`cross_mismatch_lipschitz`, `den_product_lipschitz`.

For a target sup budget `B`, the trusted gate is simply

`cross_mismatch_abs_upper <= B * actual_den_abs_lower * contract_den_abs_lower`.

For a target Lipschitz budget `L`, writing `delta=delta_a delta_c`, the trusted gate is

`delta*L_Q + E*L_P <= L*delta^2`.

All quantities can remain exact rational once the source CSE/enclosures are provided.
