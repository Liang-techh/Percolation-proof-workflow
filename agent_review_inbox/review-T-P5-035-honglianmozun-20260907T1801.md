# T-P5-035 — near-boundary exact SOS: `Q >= (18797/20000)V`

## 0. Result

For the same frozen block-(4,5) storage `V` and dissipation `Q` used in `T-P5-019`, `T-P5-033`, and `T-P5-034`, there is an exact-rational strengthening

```text
Q >= (18797/20000) V.                                  (0.1)
```

Numerically the certified coefficient is `0.93985`.  This is only `3/20000 = 0.00015` below the exact-false target `47/50 = 0.94` from `T-P5-034`; no floating spectral claim is used here.

The proof below is an explicit scaled-diagonal-dominance nine-square decomposition.  It uses no eigenvalue computation, inverse, square root, source table, Float64 semantics, ODE continuation, provenance, or admission.

Combining (0.1) with the unchanged direct residual metric of `T-P5-019`,

```text
5 ||x+y||^2 <= 17 Q,                                   (0.2)
```

gives the stronger ledger

```text
V' <= -(18797/40000)V + (17/10)||l||^2.                (0.3)
```

Relative to `T-P5-034`'s `Q >= (15/16)V`, the decay/residual capacity is multiplied by

```text
(18797/20000)/(15/16) = 18797/18750 ~= 1.00250667.     (0.4)
```

So this child adds about `0.25067%` residual headroom without any new source assumption.

## 1. Frozen exact quadratic forms

Use exactly

```text
M = diag(350003/3000000, 200739/4000000),
D = diag(4/5, 13/20),
K = [[3/4,    -3/400],
     [-3/400, 29/50]],
A = [[0, 1/400],
     [-1/400, 0]].                                      (1.1)
```

For `x=(x4,x5)` and `y=(y4,y5)`,

```text
V
 := (1/2)y^T M y
  + (1/2)x^T K x
  + x^T M y
  + (1/2)x^T D x,                                      (1.2)

Q
 := y^T(D-M)y + x^T K x - y^T A x.                    (1.3)
```

The moving-frame energy identity remains

```text

```

No physical/source definition is changed by this child.



A checker need not evaluate a square root: it may instead construct rational `p,q` and verify (7.1) and (7.3) directly.
