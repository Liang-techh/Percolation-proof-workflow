# T-P5-061 — multi-factor contact sign-action / reachable-stratum bridge

## 0. Bottleneck and non-overlap

`T-P5-057` gives the one-factor vanishing-order law

`A=h^(2m)S`, `G=h^qJ`

and shows that the balanced odd case can retain a sign jump. `T-P5-058` separates square-only consumers, `T-P5-059` gives the pure quadratic parity gate, and `T-P5-060` extends this to affine-quadratic and bilinear consumers for **one common factor** `h`.

The explicit remaining boundary in `T-P5-060` is the case where several independent zero surfaces meet, or different channels carry different radical factors. A single involution `P` is then insufficient. The correct object is a finite sign action generated by the zero surfaces actually crossed by the source domain.

This review gives that exact bridge. It is source-independent mathematics, but unlike a global `Z_2^r` over-approximation it keeps the **reachable sign subgroup** as a typed premise. That recovers one-sided/fixed-sign cells, codimension-one cells, and higher-codimension intersections from one theorem without false rejection.

No Lean compile, receipt/provenance audit, deployed source binding, Float64/libm claim, ODE/flowpipe coverage, comparator, registry mutation, or admission is performed here.

---

## 1. Multi-factor radical packet

Fix a contact stratum with active zero factors

`h_1,...,h_r`.

For channel `i`, suppose on a punctured neighborhood

**(1.1)**

`A_i = S_i * prod_a h_a^(2 m_{i,a})`,

`G_i = J_i * prod_a h_a^(q_{i,a})`,

with `S_i>0` and integers `q_{i,a} >= m_{i,a} >= 0` for every active factor.

All factors that stay bounded away from zero on this stratum may be absorbed into `S_i,J_i`; only the factors that can vanish here belong to the active list.

Define the excess orders

`k_{i,a}=q_{i,a}-m_{i,a} >= 0`

and the reduced channel

`v_i = J_i/sqrt(S_i)`.

Away from the zero surfaces, repeated use of the T-P5-057 one-factor identity gives

**(1.2)**

`u_i := G_i/sqrt(A_i)`

`= [prod_a sign(h_a)^(q_{i,a}) |h_a|^(k_{i,a})] v_i`.

For the contact value there are two cases.

### Over-cancelled on the active stratum

If `k_{i,a}>0` for at least one active factor `a`, then as all active `h_a -> 0`, the channel tends to zero whenever the remaining reduced packet stays bounded. Such a channel does not contribute a nonzero contact-side jump to an affine/quadratic/bilinear consumer.

### Balanced on the active stratum

If

`k_{i,a}=0` for every active `a`,

then channel `i` survives at contact and is controlled only by a parity mask

**(1.3)**

`alpha_i = (q_{i,1} mod 2, ..., q_{i,r} mod 2) in F_2^r`.

For a sign chamber `eps=(eps_1,...,eps_r) in {+1,-1}^r`, define the character

**(1.4)**

`chi_alpha(eps) = prod_a eps_a^(alpha_a)`.

After absorbing any fixed noncontact signs into `v_i`, the one-sided contact value is

**(1.5)**

`u_i^eps = chi_{alpha_i}(eps) v_i`.

Thus balanced contact channels form a diagonal representation of the sign group `Gamma=(Z/2)^r`.

## 2. The source-domain refinement: use the reachable sign subgroup, not automatically all of Gamma

Let `Omega` be the nonempty set of sign chambers that the **same mathematical source domain near the stratum** can approach. Choose one base side `eps0 in Omega` and define

**(2.1)**

`H = subgroup generated by { eps * eps0 : eps in Omega }`.

(Componentwise multiplication is the group law; every element is its own inverse.)

`H` is the exact relative sign-action group seen by the domain. Requiring equality across all sides in `Omega` is equivalent to invariance under `H`:

### Theorem 2.1 — reachable-side reduction

For any function `F` on the balanced contact coordinates,

`F(D_eps v)` is independent of `eps in Omega` for every `v`

if and only if

**(2.2)** `F(D_h v)=F(v)` for every `h in H` and every `v`,

where `D_h` is the diagonal character action.

### Proof

If the values agree on `Omega`, compare each `eps` with the base `eps0`. Since `D_eps=D_(eps eps0) D_eps0` and `D_eps0` is a bijective sign change, equality on the source sides gives invariance under each generator `eps eps0`, hence under the subgroup they generate.

Conversely, for any `eps in Omega`, the relative element `eps eps0` lies in `H`, so H-invariance gives `F(D_eps v)=F(D_eps0 v)`.

This theorem is the domain/stratum bridge missing from the one-factor parity packet.

### Important specializations

- **one-sided / fixed-sign cell:** `Omega` has one chamber, so `H={1}`. There is no parity obstruction. This recovers the safe fixed-sign lane of T-P5-057.
- **one active crossing factor:** `H ~= Z_2`; the theorem reduces to the even/odd split of T-P5-060.
- **full r-fold crossing:** `Omega=Gamma`, hence `H=Gamma` and all active parity bits matter.
- **constrained multi-factor crossing:** `H` can be a proper subgroup, so a global all-chambers parity test can be unnecessarily strong.

## 3. Annihilator notation

Write sign flips additively as vectors `g in F_2^r`. Then

`chi_alpha(g)=(-1)^(alpha dot g)`.

Define the annihilator

**(3.1)**

`H^perp = { alpha in F_2^r : alpha dot g = 0 mod 2 for every g in H }`.

Two channel masks have the same character on the reachable subgroup exactly when

**(3.2)**

`alpha_i + alpha_j in H^perp`.

Equivalently, they are equal after restriction to `H`.

This is the exact typed relation that a source-side parity checker needs. Global equality of bitmasks is required only when `H=Gamma`.

## 4. Affine-quadratic reachable-stratum theorem

Let `B` be the surviving balanced channel set and let

**(4.1)**

`F(u) = c + a^T u + u^T K u`,

with `K` symmetric. (For a nonsymmetric source matrix, only its symmetric part contributes to `u^T K u`; that normalization should be done before this gate.)

### Theorem 4.1 — exact H-invariance criterion

The contact value `F(D_eps v)` is independent of every reachable side `eps in Omega` for **every** reduced contact vector `v` if and only if both conditions hold:

**Affine gate**

**(4.2)** `a_i=0` whenever `alpha_i notin H^perp`.

**Quadratic gate**

**(4.3)** `K_ij=0` whenever `alpha_i + alpha_j notin H^perp`.

Equivalently, for every `h in H`,

**(4.4)** `D_h a = a`,

**(4.5)** `D_h K D_h = K`.

### Proof — sufficiency

For every `h in H`, (4.2) says every nonzero affine coefficient lies in the trivial character class, so `D_h a=a`. Condition (4.3) says every nonzero quadratic coefficient couples two coordinates with the same restricted H-character, hence `D_h K D_h=K`. Therefore

`F(D_h v)=c+a^T D_h v+v^T D_h K D_h v=F(v)`.

Theorem 2.1 then gives equality on all reachable source sides.

### Proof — necessity of the affine gate

Suppose `alpha_i notin H^perp`. Then some `h in H` has `chi_{alpha_i}(h)=-1`. Put `v=t e_i`. The diagonal quadratic term is unchanged by the sign flip, while the affine part changes by `2 a_i t`. Universal H-invariance for every real `t` forces `a_i=0`.

### Proof — necessity of the quadratic gate

Suppose `alpha_i+alpha_j notin H^perp`. Then some `h in H` has

`chi_{alpha_i}(h) chi_{alpha_j}(h)=-1`.

After the affine gate above is enforced, use `v=x e_i + y e_j`. Diagonal terms are unchanged, and the symmetric cross term changes sign. The exact jump is

**(4.6)** `4 K_ij x y`.

Universal invariance for all `x,y` therefore forces `K_ij=0`.

This proves necessity and sufficiency without eigenvalues, square roots, inverses, limits inside the trusted algebraic gate, or case splitting by matrix definiteness.

## 5. General bilinear multiplier theorem

Let `x_i` and `u_j` be two balanced channel families for the same active factors/reachable subgroup, with parity masks `alpha_i` and `beta_j`. Consider

`B(x,u)=x^T C u`.

### Theorem 5.1 — matching restricted characters

`B(D^X_eps x, D^U_eps u)` is independent of all reachable sides for every `x,u` if and only if

**(5.1)**

`C_ij=0` whenever `alpha_i + beta_j notin H^perp`.

Equivalently, a nonzero multiplier coefficient may connect two channels exactly when their characters agree after restriction to `H`.

The proof is immediate on basis vectors: the `(i,j)` monomial acquires character `alpha_i+beta_j`; it is side-invariant precisely when that character annihilates `H`.

This strictly generalizes the one-factor rule from T-P5-060:

- even-even and odd-odd are safe;
- even-odd is unsafe;
- with several factors, “same parity” means same **reachable H-character**, not necessarily identical global bitmask.

## 6. Polynomial/CSE corollary

The same rule extends beyond affine and quadratic consumers and is useful for source CSE.

For a canonical monomial

**(6.1)** `M(u)=prod_i u_i^(n_i)`,

define its parity mask

**(6.2)**

`alpha_M = sum_i (n_i mod 2) alpha_i in F_2^r`.

Then under a reachable sign action `h in H`,

**(6.3)** `M(D_h u)=chi_{alpha_M}(h) M(u)`.

Therefore:

### Corollary 6.1 — monomial gate

A monomial is structurally side-invariant on the source stratum iff

**(6.4)** `alpha_M in H^perp`.

For a polynomial written in a canonical monomial basis, universal side-invariance is equivalent to all nonzero-character components vanishing; in the common no-cancellation representation used by CSE, each retained monomial must satisfy (6.4).

This recovers:

- linear term: mask `alpha_i`;
- square `u_i^2`: mask `2 alpha_i=0`, always parity-safe;
- quadratic cross `u_i u_j`: mask `alpha_i+alpha_j`;
- cubic `u_i u_j u_k`: mask `alpha_i+alpha_j+alpha_k`.

So the consumer-side parity analysis can be performed by exact XOR/dot-product arithmetic once the source factor packet and active reachable subgroup are known.

## 7. Two exact counterexamples / boundary witnesses

### 7.1 A coupling can be safe on a codimension-one cell but fail at a higher-codimension intersection

Take two independent factors `h1=s`, `h2=t` and balanced channels

`u1 = sign(s)`,

`u2 = sign(s) sign(t)`.

Their masks are

`alpha1=(1,0)`, `alpha2=(1,1)`.

The mixed product is

**(7.1)** `u1*u2 = sign(t)`.

If the source cell crosses `s=0` but has `t>0` bounded away from zero, then the reachable subgroup is generated only by the `s` flip. The restricted characters of `alpha1` and `alpha2` agree, so the product is safely constant across that contact.

If a larger cell also contains `t=0` and reaches all nearby quadrants, then `H=F_2^2`; now the masks differ, and (7.1) jumps across the `t` sign. The same coefficient that is valid on the codimension-one stratum is invalid at the intersection.

Hence the active factor set/reachable-side group must be source-bound. A checker may neither impose the full global mask on a one-factor cell (false rejection) nor reuse a one-factor certificate on an intersection cell (false acceptance).

### 7.2 Proper reachable subgroup can make a globally odd affine channel safe

Take one balanced channel

`u=sign(h1) sign(h2)`

with mask `alpha=(1,1)`. Suppose the source domain near the contact can approach only the two diagonal sign chambers

`Omega={(+,+),(-,-)}`.

Then the relative subgroup is generated by flipping both signs simultaneously. For that generator,

`alpha dot (1,1)=0 mod 2`,

so `alpha in H^perp` and `u` has the same contact value on both reachable sides. A nonzero affine coefficient is structurally admissible on this constrained domain.

A full `Gamma` parity test would reject it incorrectly. Conversely, this relaxation is valid only if the domain restriction itself is proved; a sampled observation of two chambers is not a reachability theorem.

## 8. Minimal typed source-to-math contract

For each contact cell/stratum, the mathematical consumer needs only the following typed payload:

1. `active_factors`: exact factor IDs whose zero sets may meet the cell;
2. for each surviving balanced channel, `parity_mask alpha_i in F_2^r` produced from the exact numerator exponents after cancellation;
3. `reachable_generators`: certified relative sign flips generating `H` for the same source domain;
4. exact affine/quadratic/bilinear coefficient packet after coordinate normalization;
5. an explicit mark that every omitted channel is over-cancelled on at least one active factor and therefore has zero contact value under the bounded reduced-packet premise.

Then the structural gate uses only:

- mod-2 dot products / XOR;
- exact coefficient-zero tests;
- the generator list.

No floating square root, eigenvalue, inverse, root approximation, or branch evaluation is needed in this final consumer.

### What must not be inferred

- Interval boxes that merely *sample* sign chambers do not prove `reachable_generators`.
- A factor name shared by two formulas does not prove the same analytic zero surface.
- Global factor masks must not be used when some factors are bounded away from zero on the cell.
- A codimension-one certificate must not be lifted to an intersection without recomputing the active subgroup.
- Over-cancelled contact-value vanishing does not by itself provide a Lipschitz/derivative bound; rates remain a separate T-P5-057-type obligation.

## 9. Lean-friendly theorem decomposition

No Lean task is claimed in this review. A small formalization can avoid heavy representation theory by taking a finite list of sign generators and per-channel `±1` signatures.

Suggested minimum statements:

1. `reachable_side_eq_of_generator_invariant`
   - invariance under each supplied relative generator implies equality on every side generated from the base side.

2. `affine_quadratic_signature_gate_sufficient`
   - if every nontrivial affine signature has zero coefficient and every mismatched pair has zero cross coefficient, the affine quadratic is generator-invariant.

3. `affine_quadratic_signature_gate_necessary`
   - universal invariance for all vectors forces exactly those zero coefficients.

4. `bilinear_signature_gate_iff`
   - a coefficient survives iff the two generator-signature vectors agree.

5. `monomial_signature_product`
   - the signature of a monomial is the product/XOR of signatures of variables with odd exponent.

The factor-to-signature theorem can remain a separate child consuming the existing one-factor radical identities, so the trusted parity core stays finite/algebraic.
