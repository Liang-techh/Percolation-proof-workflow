# T-P5-095 — moving-chart naturality of the base-flow Lie defect

## 0. Question and scope

T-P5-090 established exact pullback congruence for the **nominal** moving-metric
contraction tensor.  T-P5-093 then identified the exact defect generated by a
change of physical base flow

`xdot = -F(t,x)`  ->  `xdot = -F(t,x) + b(t,x)`

as the single signed tensor

`S_b := D_x W[b] + (D_x b)^T W + W D_x b`.

T-P5-093 explicitly left open whether this base-flow Lie defect itself transports
naturally through a moving nonlinear chart.  This is not merely cosmetic: if a
source adapter normalizes state coordinates and then bounds `b`, `Db`, `DW`
independently in the normalized variables, it can introduce artificial chart
condition-number and Hessian charges or, worse, transform the perturbation as a
scalar rather than as a vector field.

This child proves the exact bridge.  The result is:

**the base-flow Lie defect is a covariant 2-tensor under the same chart pullback
used for the metric.**

Consequently the signed relative rate loss `rho` from T-P5-093 is invariant under
an arbitrary sufficiently smooth moving nonlinear chart, provided the base
perturbation itself obeys the correct vector-field covariance.

No deployed source binding, Float64/FD/controller/P8 semantics, Lean receipt,
provenance/admission, or registry promotion is claimed here.

## 1. Setup and the correct perturbation covariance

Fix a time `t`.  Let

`x = T(t,z)`

be a `C^2` state chart on the relevant cell/tube and write

`J(z) := D_z T(t,z)`.

Let the physical metric be the symmetric matrix field

`W(t,x)`

and define its pulled-back metric

**(1.1)**

`M(t,z) := J(z)^T W(t,T(t,z)) J(z)`.

Suppose the nominal physical vector field is `-F` and the actual physical vector
field differs by `+b`:

`xdot_nom = -F(t,x)`,

`xdot_act = -F(t,x) + b(t,x)`.

For the nominal transformed field `-G`, the moving-chart covariance is

`J G = F o T + T_t`.

If the actual normalized flow is written

`zdot_act = -G(t,z) + c(t,z)`,

then substitution into `xdot = T_t + J zdot` gives the **exact perturbation
covariance**

**(1.2)**

`J(z) c(t,z) = b(t,T(t,z))`.

Notice that `T_t` cancels when one subtracts the nominal and perturbed equations.
Thus the base perturbation transforms as a tangent vector; it is not obtained by
merely composing its coordinate components with `T`.

The forward theorem below never requires an explicit `J^{-1}`.  One may treat
`c` as a source witness satisfying (1.2).

## 2. Differential covariance identity

Write

`B(x) := D_x b(t,x)`,

`C(z) := D_z c(t,z)`.

Differentiate (1.2) in a direction `eta`:

`D_z(Jc)[eta] = D_x b(T(z))[J eta]`.

The left-hand side is

`(D_z J[eta]) c + J C eta`.

Because `T` is `C^2`, its second derivative is symmetric in the two direction
slots, hence

`(D_z J[eta]) c = (D_z J[c]) eta`.

Therefore for every `eta`,

`(D_z J[c] + J C) eta = (B o T) J eta`.

So we obtain the exact matrix identity

**(2.1) DIFFERENTIATED VECTOR COVARIANCE**

`D_z J[c] + J D_z c = (D_x b o T) J`.

This is the entire connection-cancellation mechanism needed below.

A source adapter does not need to invert `J` to use (2.1).  It may expose
`J,c,C,B` and prove the multiplication identity directly.

## 3. Exact pullback congruence for the Lie defect

Define the physical base-flow Lie-defect tensor at `x=T(z)` by

**(3.1)**

`S_b`
`:= D_x W[b] + B^T W + W B`.

Define the corresponding normalized object using the pulled metric `M` and the
normalized base perturbation `c`:

**(3.2)**

`S_c`
`:= D_z M[c] + C^T M + M C`.

We now expand the directional derivative of (1.1).  Suppressing the common
arguments `t,z,T(t,z)`, the product/chain rule gives

**(3.3)**

`D_z M[c]`
`= (D_z J[c])^T W J`
`  + J^T D_x W[Jc] J`
`  + J^T W D_z J[c]`.

Add the two Jacobian terms generated by `C=D_zc`:

`C^T M + M C`
`= C^T J^T W J + J^T W J C`.

Group the first and fourth terms, and the third and fifth terms:

`S_c`
`= (D_zJ[c] + J C)^T W J`
`  + J^T D_xW[Jc] J`
`  + J^T W (D_zJ[c] + J C)`.

Use the two exact covariance identities

`Jc = b o T`,

`D_zJ[c] + JC = (B o T)J`.

Then

`S_c`
`= J^T B^T W J`
`  + J^T D_xW[b] J`
`  + J^T W B J`.

Therefore:

**(3.4) MAIN PULLBACK LIE-DEFECT THEOREM**

`S_c(t,z) = J(z)^T S_b(t,T(t,z)) J(z)`.

This is an exact identity.  There is no Hessian penalty, chart condition-number
factor, or extra moving-frame remainder.  The `D^2T` terms hidden inside
`D_zJ[c]` cancel against the derivative of the transformed vector field through
(2.1).

This is the coordinate form of the naturality identity

`T^*(Lie_b W) = Lie_c(T^*W)`

under `T_* c=b`.

## 4. Exact transport of the relative rate loss

For a symmetric matrix field `R`, write

`Q_R(v) := v^T R v`.

Suppose the physical same-tube source certificate from T-P5-093 is

**(4.1)**

`Q_{S_b}(xi) <= 2 rho Q_W(xi)`

for every relevant physical tangent vector `xi`.

Take any normalized tangent vector `eta` and set

`xi = J eta`.

By (1.1) and (3.4),

`Q_{S_c}(eta) = Q_{S_b}(J eta)`,

`Q_M(eta) = Q_W(J eta)`.

Hence (4.1) immediately implies

**(4.2) RATE-LOSS PULLBACK**

`Q_{S_c}(eta) <= 2 rho Q_M(eta)`.

Thus **the same scalar `rho` transports with no degradation**.

The forward implication requires no invertibility assumption on `J`: it is just
quadratic-form substitution.  If one wants an iff between all physical and all
normalized tangent vectors, or equality of genuine metric geometries, then the
usual chart-rank/invertibility hypotheses are required separately.

A signed favorable perturbation is also preserved.  If `rho<0` physically, the
same negative `rho` remains valid in normalized coordinates.

## 5. Perturbed contraction tensor also transports exactly

T-P5-090 gives the nominal moving-chart contraction congruence

**(5.1)**

`C0_z = J^T C0_x J`.

T-P5-093 gives the perturbed physical contraction tensor

**(5.2)**

`Cact_x = C0_x - S_b`.

The normalized perturbed tensor is correspondingly

`Cact_z = C0_z - S_c`.

Using (3.4) and (5.1),

**(5.3) FULL PERTURBED-TENSOR CONGRUENCE**

`Cact_z`
`= J^T C0_x J - J^T S_b J`
`= J^T (C0_x-S_b) J`
`= J^T Cact_x J`.

Therefore if the physical source packet proves

`C0_x >= 2 mu W`

and

`S_b <= 2 rho W`,

then the normalized packet proves

`Cact_z >= 2(mu-rho) M`

with the **same** `mu` and `rho`.

This closes the mathematical naturality seam between T-P5-090 and T-P5-093.

## 6. Minimal typed source-to-math contract

A checker should not ask a normalized source lane to compute `J^{-1}` and then
bound the resulting expressions independently.  A smaller and safer packet is:

1. same-point binding `x=T(t,z)`;
2. chart Jacobian `J=D_zT`;
3. physical metric and derivative packet `W`, `D_xW`;
4. physical base perturbation and derivative packet `b`, `B=D_xb`;
5. normalized base perturbation and derivative packet `c`, `C=D_zc`;
6. exact vector covariance
   `J c = b o T`;
7. exact differentiated covariance
   `D_zJ[c] + J C = (B o T)J`;
8. pulled metric identity
   `M=J^T(W o T)J`;
9. a physical signed quadratic certificate
   `S_b <= 2 rho W`.

The trusted bridge then needs only matrix addition/multiplication/transposition
and quadratic-form substitution.

If the source already proves that `c` is differentiable and (1.2) is an exact
functional identity, item 7 can be derived rather than stored.  In a more
algebraic/CSE pipeline it can instead be supplied as an explicit child equality,
which avoids asking the trusted core to differentiate source syntax.

### 6.1 Denominator-cleared variant

Even when a source originally obtains `c` from `c=J^{-1}(b o T)`, the trusted
interface need not contain an inverse.  It is enough to retain the multiplicative
identity

`Jc=b o T`.

Likewise, instead of forming `C` by differentiating a symbolic inverse, retain

`D_zJ[c] + JC = BJ`.

This is the same design principle used in earlier descriptor/adjugate bridges:
move inverse construction out of the trusted scalar gate and retain the exact
multiplication identity that characterizes the desired quantity.

## 7. Exact obstruction A — treating a vector field as a scalar under scaling

The perturbation covariance (1.2) is mandatory.

Take one dimension, constant physical metric

`W=1`,

linear chart

`T(z)=2z`, so `J=2`,

and physical base perturbation

`b(x)=x`.

Then

`Db=1`,

so the physical Lie defect is

`S_b = 2`.

The pulled metric is

`M=J^2 W=4`.

The **correct** normalized perturbation solves

`2 c(z)=b(2z)=2z`,

hence

`c(z)=z`, `Dc=1`.

Therefore

`S_c = 2 M Dc = 8`,

and indeed

`J^T S_b J = 2*2*2 = 8`.

Now make the common but incorrect scalar-composition choice

`c_wrong(z):=b(T(z))=2z`.

Then `Dc_wrong=2`, so

`S_wrong = 2 M Dc_wrong = 16`.

The true pullback value is `8`, not `16`.

Thus forgetting the contravariant vector transformation produces a spurious
factor of two already under a constant linear scaling.  In higher dimensions it
can alter directions as well as magnitudes.

## 8. Exact obstruction B — absolute-first Hessian charging destroys naturality

Equation (3.3) contains chart-curvature terms

`(D_zJ[c])^T WJ + J^T W D_zJ[c]`.

The transformed vector Jacobian contributes

`C^T J^T WJ + J^TWJC`.

These terms are not independent errors.  Their signed sums are exactly

`(D_zJ[c]+JC)^T WJ`

and

`J^TW(D_zJ[c]+JC)`,

which become `J^TB^TWJ` and `J^TWBJ` by (2.1).

Therefore a source lane that first applies entrywise absolute values to
`D_zJ[c]` and `JC` can manufacture a large artificial nonlinear-chart charge
that is absent from the physical Lie derivative.  The correct order is:

`J,c,B,C,DJ[c]`
` -> form the signed covariance combination DJ[c]+JC`
` -> replace it by BJ`
` -> form the full signed Lie tensor`
` -> only then enclose the quadratic form`.

This is the same structural cancellation principle already encountered for the
nominal moving metric and for signed Gram/adjugate packets.

## 9. Exact obstruction C — covariance mismatch is a real extra defect

Suppose an executable normalized model exports `chat` but source only proves

`J chat = b o T - r`

with a nonzero residual `r`.

Then `chat` is **not** the exact transformed base perturbation.  In physical
coordinates the normalized implementation corresponds to a base perturbation
`b-r` (with the appropriate sign convention), and the missing `r` changes both
the base trajectory and, if state dependent, the metric transport.

It is therefore unsound to use the exact theorem above for `b` while silently
ignoring `r` or charging it only as an additive variation-level defect.  One must
either:

- rebind the physical base perturbation to the actual `b-r` and form its full
  Lie defect; or
- derive a separate base-flow mismatch packet for `r`, including its derivative
  and `D_xW[r]` contribution.

This is precisely the type boundary emphasized by T-P5-093: a base-flow error is
not interchangeable with a variational residual.

## 10. Interaction with T-P5-091 and T-P5-094

Once (4.2) has transported `rho`, T-P5-093/T-P5-091 may continue exactly as in
physical coordinates.  If an additional *true variational* relative defect has
rate `sigma`, define

`nu = mu-rho-sigma`.

The mixed invariant-tube theorem then uses the same `nu` in the pulled metric
`M`; there is no extra chart-curvature debit from the base perturbation.

Likewise, if a homogeneous differential contraction packet is later converted
to T-P5-094 path-energy contraction, the rate inserted into the rational decay
factor is the already debited `mu-rho` (or `mu-rho-sigma`).  This child does not
redo the path-energy theorem and does not claim its path-sheet coverage.

## 11. Assumptions and fail-closed boundaries

The exact identity (3.4) requires:

- enough spatial regularity for `T` to have symmetric second derivative and for
  `c,b,W` to have the displayed derivatives;
- a single common time and source point relation `x=T(t,z)`;
- exact covariance `Jc=b o T`;
- the same physical metric `W` in the nominal and perturbed packets;
- the same physical perturbation `b` in `b`, `Db`, and `D_xW[b]`.

The theorem does **not** prove:

- that the deployed chart is injective or globally invertible;
- that a deployed cell/tube is mapped into the physical contraction-certified
  tube;
- that actual controller/FD/solver discrepancy really equals the proposed `b`;
- that `Db`, `DW`, `J`, `DJ`, `c`, or `C` come from the same executable source;
- coercivity of `W` or `M` as genuine norms;
- finite-step integrator error, Float64 semantics, or P8/flowpipe coverage;
- Lean/kernel compilation, independent verification, admission, or registry
  propagation.

If same-tube covariance/source binding fails, the result is
`NOT_CERTIFIED/NOT_APPLICABLE` for this bridge; it is not evidence that the
physical dynamics is noncontracting.

## 12. Minimal theorem statements for formalization

A first Lean pass should remain finite-dimensional and algebraic once the
calculus identity (2.1) is supplied.

### Leaf A — differentiated covariance consumer

`pullback_base_lie_defect_identity`

Inputs at one point:

`M = J^T W J`,

`Jc = b`,

`K + J C = B J`,

`DMc = K^T WJ + J^T DWb J + J^T W K`.

Conclude

`DMc + C^T M + M C`
`= J^T (DWb + B^T W + W B) J`.

Here `K` represents `D_zJ[c]` and `DWb` represents `D_xW[b]`; the theorem itself
is pure matrix algebra and does not need a differential-geometry API.

### Leaf B — signed rate transport

`base_lie_defect_rate_pullback`

From

`Q_Sb(J eta) <= 2 rho Q_W(J eta)`,

`M=J^TWJ`, `Sc=J^TSbJ`,

conclude

`Q_Sc(eta) <= 2 rho Q_M(eta)`.

### Leaf C — perturbed contraction congruence

`perturbed_contraction_tensor_pullback`

From

`C0z=J^TC0xJ`, `Sc=J^TSbJ`,

prove

`C0z-Sc = J^T(C0x-Sb)J`.

### Leaf D — regression counterexample

`wrong_scalar_composition_changes_lie_defect_under_scaling`

Instantiate the 1D rational data

`J=2, W=1, b(x)=x, c=z, c_wrong=2z`

and verify exact values

`Sb=2`, `M=4`, `Sc=8`, `Swrong=16`.

The calculus wrapper deriving `K+JC=BJ` from the functional covariance can be a
separate later theorem.  This keeps the first trusted child very small.

## 13. Bottom line

The missing naturality statement from T-P5-093 is exact:

**`Lie_c(T^*W) = T^*(Lie_b W)` whenever `T_*c=b`.**

In coordinates,

**`D_zM[c] + (Dc)^T M + M Dc`
`= J^T (D_xW[b] + (Db)^T W + WDb) J`.**

Hence the signed base-flow contraction debit `rho` is chart invariant under the
same pulled metric used by T-P5-090.  Nonlinear chart Hessian terms do not incur
an additional penalty; they cancel exactly against the derivative of the
properly transformed perturbation field.  The actual remaining frontier is now
source-level: bind one same-tube packet for `T/J`, `W/DW`, `b/Db`, and `c/Dc`
with `Jc=b o T` (or its denominator-cleared equivalent), then apply the physical
signed Lie-defect bound.  Until that binding exists, admission remains pending.
