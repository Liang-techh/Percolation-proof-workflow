**(0.3) SHARP OBSERVABLE BOUND**

`(c_s^T x)^2 <= A * (x^T P x) = 2 A Vc(x)`.

The coefficient multiplying `Vc` is

`2A = 22551240/75672601 ~= 0.298010636637`,

## 2. Division-free proof of the sharp observable constant

Write

`n=11275620`, `d=75672601`, so `A=n/d`.

Let

`s := c_s^T x = e^T P x`.

Because `P` is positive definite,

`0 <= (n x - d s e)^T P (n x - d s e)`.

Using `e^T P x=s` and `e^T P e=n/d`, the left side expands exactly to

`n * (n x^T P x - d s^2)`.

Since `n>0`,

**(2.1)** `d s^2 <= n x^T P x`.

Equivalently,

**(2.2)**

`75672601 * (c_s^T x)^2`
` <= 22551240 * Vc(x)`.

This proof uses no matrix inverse, square root, eigenvalue, spectral norm, or floating-point constant. It is a single nonnegative quadratic square plus ring normalization.

## 4. Sharp ellipsoid-to-ellipsoid jump gate

Let

`V(x)=1/2 x^T P x`, `P>0`, `A=e^T P e>0`,

and consider the translation

`x+ = x- - Delta e`.

**(4.1)**

`sup V(x- - Delta e)`
` = Rin + |Delta|*sqrt(2*A*Rin) + (A/2)Delta^2`.

The supremum is attained by the adverse aligned state `x-` parallel to `-sign(Delta)e`. Thus this is an exact geometric statement, not merely Cauchy-Schwarz slack.

Consequently the full ellipsoid inclusion

**(4.2)**

`V(x-)<=Rin  ->  V(x-Delta e)<=Rout`

holds for every `x-` if and only if, with

`B := H - (A/2)Delta^2`,

**(4.3)** `B>=0`,

**(4.4)** `B^2 >= 2*A*Rin*Delta^2`.

Conditions (4.3)-(4.4) contain no square root and are necessary and sufficient.

For the exact T-P5-106 rational `A=n/d`, define

`Bnum := 2*d*H - n*Delta^2`.

**(4.5)** `Bnum >= 0`,

**(4.6)** `Bnum^2 >= 8*n*d*Rin*Delta^2`.

Numerically the integer product is

`8*n*d = 6826043946300960`.

So the checker needs only rational addition, multiplication, squaring, and order.

## 7. What failed / what must not be inferred

### 7.1 Do not continue to use `Qd<=25Vc` for this jump observable

That route loses the exact relation `c_s=P e`. It is valid but introduces more than a factor-26 slack in the squared storage coefficient.

### 7.2 Do not replace a direct flow-plus-jump gate by a reset budget computed at the outer collar

After a certified dwell, the pre-jump ellipsoid is smaller. Throwing away that contraction before evaluating the translation can turn a certifiable schedule into a false negative, as section 6 shows.

### 7.3 Equality is not strict reserve

The aligned rational witness in section 4 reaches the target boundary exactly when the square gate is equality. Strict inwardness requires strict scalar reserve.

### 7.4 The sharpness is only for the information actually used

The theorem is sharp for the complete ellipsoid `Vc<=Rin` under the exact translation `x+=x-Delta e`. A smaller reachable subset, signed correlation, or additional state constraint can improve the jump bound further. Conversely, without the exact translation/source identity, this theorem must not be applied.
