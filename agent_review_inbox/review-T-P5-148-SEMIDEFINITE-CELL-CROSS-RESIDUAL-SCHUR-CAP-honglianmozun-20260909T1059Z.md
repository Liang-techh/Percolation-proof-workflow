# T-P5-148 — semidefinite-cell cross residual: augmented Schur cap with signed quotient correction

## 0. Narrow seam and non-overlap

T-P5-144 eliminates the uncontrolled physical-cell nullspace exactly under

`A >= 0`, `A u = b_N`, `A L = H_NM`.

T-P5-147 relaxes only the affine solve `A u=b_N` and deliberately keeps the cross solve `A L=H_NM` exact.  Its companion explicitly leaves the case of an inexact cross solve as a separate matrix-valued child.

This review closes that seam.  The main point is stronger than a norm bound:

- a cross residual on an unbounded `ker G` direction is harmless **iff it is itself range-compatible with `A`**;
- the correct root-free certificate is a block PSD / generalized Schur cap;
- the cross residual does not produce an additive scalar floor by default; it produces a **signed quotient curvature correction**;
- if affine and cross residuals are simultaneously present, their cancellation should be retained in one augmented PSD packet rather than charged independently.

T-P5-146 concerns the later singular-multiplier dual canonicalization and is not repeated here.  No source binding, provenance/admission, Lean/kernel compile, runtime/Float64 semantics, coverage, registry mutation, or P5 parent closure is attempted.

## 1. Starting quadratic and two residuals

Use the T-P5-144 split of the semidefinite physical-cell metric.  The quotient coordinate is `m`, the uncontrolled physical nullspace coordinate is `n`, and

`A=A^T >= 0`

is the nullspace block of the reset curvature.  Write

`f(m,n)`

`:= C + b_M^T m + b_N^T n`

`   - m^T H_MM m - 2 m^T H_MN n - n^T A n`.

Choose arbitrary candidate witnesses `u` and `L`, not assumed exact, and define

**(1.1)** `r := b_N - A u`,

**(1.2)** `D := H_NM - A L`.

Thus `r` is the affine residual handled by T-P5-147 when `D=0`, while `D` is the new matrix-valued cross residual.

Set

**(1.3)** `e := n-u/2+L m`.

Define the preliminary quotient coefficients

**(1.4)** `C_0 := C + (u^T A u)/4 + (r^T u)/2`,

**(1.5)** `b_0 := b_M - L^T b_N - D^T u`,

**(1.6)**

`H_0 := H_MM - L^T A L - D^T L - L^T D`.

`H_0` is symmetric.

### Lemma 1 — exact residual identity

For every `(m,n)`,

**(1.7)**

`f(m,n)`

`= C_0 + b_0^T m - m^T H_0 m`

`  + r^T e - 2 e^T D m - e^T A e`.

### Proof

Use `b_N=A u+r` and `H_NM=A L+D`, hence `H_MN=L^T A+D^T`, substitute

`n=e+u/2-Lm`,

and collect constant, linear, quadratic, and `e` terms.  The quadratic correction generated by the cross residual is

`m^T(D^T L+L^T D)m`,

which is why both signed terms occur in (1.6).

This identity is the only algebra needed below.

## 2. One augmented residual map preserves affine/cross cancellation

Introduce

**(2.1)** `xi := (1,m)`,

and the linear residual map

**(2.2)** `Q := [ r , -2D ]`,

so that

`Q xi = r-2Dm`.

Then the uncontrolled residual contribution in (1.7) is

**(2.3)**

`Phi(e,xi) := e^T Q xi - e^T A e`.

Do **not** first bound `r^T e-e^T A e` and `-2e^TDm-e^TAe` separately: both would spend the same `A`-curvature and erase the signed correlation between `r` and `Dm`.

Instead choose a symmetric matrix `Sigma` on the augmented coordinate `(1,m)` and require the single block PSD gate

**(2.4)**

`M_Sigma := [[ A,       -Q/2 ],`

`            [ -Q^T/2,  Sigma ]] >= 0`.

### Theorem A — root-free augmented residual cap

Under (2.4),

**(2.5)** `Phi(e,xi) <= xi^T Sigma xi`

for every `e,m`.

### Proof

The block quadratic is exactly

`[e;xi]^T M_Sigma [e;xi]`

`= e^T A e - e^T Q xi + xi^T Sigma xi`

`= xi^T Sigma xi - Phi(e,xi)`.

PSD therefore gives (2.5) directly.  No inverse, pseudoinverse, square root, eigenvalue, Young split, or nullspace basis is required by the trusted consumer.

## 3. Exact existence classification and Loewner-minimal cap

The block cap is not merely sufficient.  It captures exactly the finite-escape condition.

### Theorem B — augmented range criterion

Assume `A=A^T>=0`.  The following are equivalent:

1. `range(Q) subseteq range(A)`;
2. `r in range(A)` and `range(D) subseteq range(A)`;
3. there exists some finite symmetric `Sigma` for which (2.4) holds.

When these conditions hold, choose any matrix `X` satisfying

**(3.1)** `A X=Q`.

Then the matrix

**(3.2)** `Sigma_* := (1/4) Q^T X = (1/4) X^T A X`

is well-defined, symmetric, PSD, independent of the chosen range solve `X`, and satisfies

**(3.3)**

`e^T A e-e^T Q xi+xi^T Sigma_* xi`

`= (e-X xi/2)^T A(e-X xi/2) >=0`.

Thus `Sigma_*` is admissible.

Moreover, for every other admissible `Sigma`,

**(3.4)** `Sigma-Sigma_* >=0`.

So `Sigma_*` is the unique Loewner-minimal augmented quadratic tax.

### Proof of minimality

Take the PSD quadratic from (2.4) and evaluate it at

`e=X xi/2`.

Because `AX=Q`, the value is exactly

`xi^T(Sigma-Sigma_*)xi`.

It is nonnegative for every `xi`, proving (3.4).

### Proof that a cap forces the range condition

Let `k in ker A`.  For any augmented vector `xi`, test the block quadratic on `(t k,xi)`.  Its `t^2` coefficient is zero and its linear coefficient is

`-t k^T Q xi`.

A quadratic affine in `t` cannot be nonnegative for both signs and arbitrarily large `|t|` unless

`k^T Q xi=0`

for every `k,xi`.  Therefore every column of `Q` is orthogonal to `ker A`; symmetry of `A` gives

`range(Q) subseteq (ker A)^perp = range(A)`.

This is the exact fail-closed reason ordinary small residual norms are insufficient.

## 4. Cross-only specialization: matrix residual costs curvature, not a scalar floor

Now impose the exact affine solve

**(4.1)** `A u=b_N`,

so `r=0`, while allowing

`D=H_NM-A L`

to be nonzero.

Then the augmented theorem reduces to a smaller block gate.  Choose symmetric `S` and require

**(4.2)**

`[[ A,   D ],`

` [ D^T, S ]] >=0`.

For every `e,m`,

**(4.3)**

`-2e^T Dm-e^T A e <= m^T S m`.

Therefore (1.7) gives

**(4.4)**

`f(m,n) <= C_0+b_0^T m-m^T(H_0-S)m`.

So an inexact cross solve produces a **quotient curvature tax `S`**, not an additive constant tax.

If an exact correction `Z` exists with

**(4.5)** `A Z=D`,

then the intrinsic minimal curvature tax is

**(4.6)** `S_*:=D^T Z=Z^T A Z >=0`.

It is independent of the chosen `Z`, and every admissible `S` satisfies

**(4.7)** `S-S_*>=0`.

With `S=S_*`,

**(4.8)**

`e^T A e+2e^TDm+m^T S_*m`

`=(e+Zm)^T A(e+Zm)`.

Thus the constant is sharp and the completion is exact.

### Finiteness classification on a positive-radius cylindrical cell

Assume the quotient metric `G_M>0` and physical radius `R>0`, so every sufficiently small quotient direction is physically admissible.  Then the cross-residual contribution has a finite uniform upper bound on

`m^T G_M m<=R`, `n arbitrary`

**iff**

**(4.9)** `range(D) subseteq range(A)`.

If (4.9) fails, there exist `k in ker A` and a quotient direction `m_0` with

`k^T D m_0 !=0`.

Choose a nonzero sufficiently small scalar `eps` so that `m=eps m_0` lies in the cell, and take `e=t k`.  Then

`-2e^T Dm-e^T A e = -2t k^T Dm`,

which tends to `+infinity` for one sign of `t`.

No multiplier `tau`, Young parameter, or finite additive reset budget can repair this branch before the range defect is removed.

## 5. Simultaneous affine + cross residual: exact signed quotient packet

The augmented form is most useful when T-P5-147's affine residual and the new cross residual occur together.

Partition the admissible cap as

**(5.1)**

`Sigma = [[ alpha, g^T/2 ],`

`         [ g/2,   S     ]]`.

Then

`xi^T Sigma xi = alpha+g^T m+m^T S m`.

Define

**(5.2)** `C_bar := C_0+alpha`,

**(5.3)** `b_bar := b_0+g`,

**(5.4)** `H_bar := H_0-S`.

### Theorem C — simultaneous residual quotient reduction

If (2.4) holds, then on all states

**(5.5)**

`f(m,n) <= C_bar+b_bar^T m-m^T H_bar m`.

More strongly, the gap is exactly

**(5.6)**

`C_bar+b_bar^T m-m^T H_bar m-f(m,n)`

`= [e;xi]^T M_Sigma [e;xi] >=0`.

This is a clean algebraic handoff: all nullspace uncertainty is summarized by the signed triple `(alpha,g,S)`, while the quotient consumer receives an ordinary quadratic reset packet.

The middle vector `g` is important.  It records real cancellation between the affine and cross residuals.  Replacing the augmented packet by independent absolute caps generally loses this information and overcharges the quotient.

## 6. Exact corrected witnesses recover T-P5-144 with zero artificial slack

Suppose the range conditions hold and choose exact corrections

**(6.1)** `A z=r`,

**(6.2)** `A Z=D`.

Take

**(6.3)** `X=[z,-2Z]`.

Then the minimal cap (3.2) has the explicit partition

**(6.4)**

`alpha_* = (r^T z)/4`,

**(6.5)** `g_* = -D^T z`,

**(6.6)** `S_* = D^T Z`.

Indeed

`Sigma_*`

`= [[ (r^Tz)/4, -(r^T Z)/2 ],`

`   [ -(D^Tz)/2, D^T Z ]]`,

and `r^T Z=z^T D`.

Define corrected exact witnesses

**(6.7)** `u_*:=u+z`,

**(6.8)** `L_*:=L+Z`.

Then

`A u_*=b_N`,

`A L_*=H_NM`.

Substituting `(alpha_*,g_*,S_*)` into (5.2)-(5.4) gives exactly the T-P5-144 quotient coefficients:

**(6.9)** `C_bar = C + b_N^T u_*/4`,

**(6.10)** `b_bar = b_M-H_MN u_* = b_M-L_*^T b_N`,

**(6.11)** `H_bar = H_MM-H_MN L_* = H_MM-L_*^T A L_*`.

Hence the augmented residual theorem is not a relaxed alternative to exact nullspace elimination.  At its Loewner-minimal cap it **is exactly the same quotient problem**, recovered without requiring the consumer to use an inverse or pseudoinverse.

Any larger admissible `Sigma` has a single explicit slack matrix

`DeltaSigma:=Sigma-Sigma_*>=0`.

That slack may change the quotient constant, linear coefficient, and curvature jointly; it should not be silently split into unrelated scalar taxes.

## 7. Signed-cancellation example: why the augmented cap is materially sharper

Take the scalar nullspace block

`A=1`,

with simultaneous residuals

`r=1`, `D=1`.

Then

`Q=[1,-2]`,

and the uncontrolled residual is

**(7.1)**

`Phi(e,m)=e(1-2m)-e^2`.

The exact supremum over `e` is

**(7.2)**

`sup_e Phi(e,m)=(1-2m)^2/4`

`=1/4-m+m^2`.

The minimal augmented cap is therefore

**(7.3)**

`Sigma_*=[[1/4,-1/2],[-1/2,1]]`,

corresponding to

`alpha_*=1/4`, `g_*=-1`, `S_*=1`.

At `m=1/2`, the affine and cross residuals cancel exactly and the true residual cost is **zero**.

Any architecture that first takes unsigned caps of the affine and cross pieces separately cannot see this cancellation.  The augmented Schur packet preserves it automatically through the signed linear correction `g`.

This is the same structural principle used elsewhere in the energy/Lyapunov lane: form the signed power/quadratic identity first; norm or interval charging should be the last fallback, not the first operation.

## 8. Fatal small-norm counterexample for the cross residual

Let

`A=diag(1,0)`,

and take a one-dimensional quotient variable with

**(8.1)** `D=(0,epsilon)^T`

for any nonzero rational/real `epsilon`, however small.

Then `range(D)` is not contained in `range(A)`.  For `m!=0` and

`e=(0,t)`,

**(8.2)**

`-2e^TDm-e^TAe = -2 epsilon m t`.

One sign of `t` sends this to `+infinity`.

Equivalently, no finite `S` can make

`[[A,D],[D^T,S]]>=0`:

testing the PSD quadratic on `(t(0,1),m)` produces an affine function of `t` with nonzero slope.

Therefore the following are invalid replacements for the range/PSD certificate on a cylindrical physical cell:

- a small Frobenius norm of `D`;
- a small componentwise Float64 residual;
- a small relative solver tolerance;
- a statement that `A L` is numerically close to `H_NM`.

Any unresolved component in `ker A` is a genuine unbounded-energy escape, not merely a numerical looseness.

## 11. What this changes in the P5 decision tree

For a semidefinite physical-cell metric, use this order:

1. expose the actual uncontrolled nullspace block `A`;
2. form signed residuals `r=b_N-Au` and `D=H_NM-A L`;
3. if both are zero, use T-P5-144 directly;
4. if only `r` is nonzero and `D=0`, T-P5-147's scalar rank-one cap is sufficient;
5. if `D!=0`, prefer the single augmented block PSD cap (2.4), because it retains affine/cross cancellation;
6. if no augmented cap exists, report the exact `ker A` escape obstruction instead of tuning quotient multipliers;
7. only after successful nullspace reduction run the positive-definite quotient multiplier chain.

The key structural fingerprint is:

> **cylindrical-nullspace residuals must be range-eliminated before they are budgeted; matrix-valued cross residuals tax quotient curvature, while simultaneous affine/cross residuals naturally produce a signed constant/linear/curvature Schur packet.**

This is the energy-level analogue of preserving nonlinear cancellation before taking absolute values.
