# T-P5-180 — corank-one anchor-deletion Schur reduction

## 0. Verdict and seam closed

**CONDITIONAL_PASS_MATHEMATICAL_CHILD / pending source binding.**

T-P5-178 proves the correct general second-order rule at a strict positive zero contact: every zero-residual inactive row must annihilate the entire active kernel, equivalently lie in `range(A)`, before the critical block can be reduced by a Schur solve. T-P5-179 then proves that an arbitrary orthant contact should first descend to its true positive support.

This review closes the important **corank-one specialization** of that seam.

If the canonical active block `A` is PSD and has exactly one kernel direction, generated by the strict positive contact `z>0`, then the hidden-kernel obstruction disappears automatically:

> for every critical inactive row `b` satisfying the ordinary contact equation `b^T z=0`, one automatically has `b in range(A)`.

Moreover, no generalized inverse or arbitrary range solve is needed. Choose any active anchor coordinate `a`. Because `z_a>0`, deleting row/column `a` from `A` produces an ordinary SPD principal block `A_hat`. The whole T-P5-178 mixed critical-cone problem then reduces to one standard Schur complement through `A_hat`.

For rational data, the reduction has a completely division-free form

`Q_a = det(A_hat) C - B_hat adj(A_hat) B_hat^T`.

Since `det(A_hat)>0`, the original mixed critical block is nonnegative on `R^S x R_+^I` iff `Q_a` is copositive. For a single critical inactive row this is only one determinant inequality.

This is a mathematical routing result only. It does not establish actual source identity, global copositivity over all supports, runtime/Float64 semantics, Lean/kernel validation, independent verification, registry admission, or P5 parent closure.

## 1. Setup

Let

`A=A^T in R^{m x m}`

and assume

1. `A >= 0`;
2. `rank(A)=m-1`;
3. `ker(A)=span{z}` for some `z>0` coordinatewise.

Let `I` be a finite set of critical inactive coordinates. Collect their couplings to the active block into

`B in R^{p x m}`

and their inactive self-block into

`C=C^T in R^{p x p}`.

At a zero contact, the critical-row condition is exactly

`B z = 0`.

The mixed critical quadratic form from T-P5-178 is

`Phi(u,y) = u^T A u + 2 y^T B u + y^T C y`,

with

`u in R^m`, `y in R_+^p`.

The question is to decide

`Phi(u,y)>=0`

for every such `(u,y)` without pseudoinverses and without a separate hidden-kernel search.

---

## 2. T180-A — corank one makes zero residual equivalent to range compatibility

### Theorem

Under the setup above,

`B z=0`

implies

`range(B^T) subseteq range(A)`.

Equivalently, every critical row transpose lies in `range(A)`.

### Proof

For a real symmetric matrix,

`range(A) = ker(A)^perp`.

Because `ker(A)=span{z}`,

`range(A) = z^perp`.

The equation `Bz=0` says exactly that every row `b_i` of `B` is orthogonal to `z`. Therefore every `b_i^T` belongs to `z^perp=range(A)`.

QED.

### Why this matters

In the general higher-corank theorem T-P5-178, the scalar contact equation

`b_i^T z=0`

checks only one kernel vector and is not sufficient: the row may still couple to another hidden kernel direction. Corank one is exactly the regime where the chosen positive contact spans the entire kernel, so there is no hidden direction left to test.

Thus the T-P5-178 range-compatibility gate can be removed entirely in this branch.

## 3. T180-B — deleting any positive anchor gives an SPD block

Choose any active index `a`.

Because `z>0`,

`z_a>0`.

Let `A_hat` denote the principal matrix obtained by deleting row and column `a` from `A`.

### Theorem

`A_hat > 0`.

In particular,

`det(A_hat)>0`.

### Proof

Since `A>=0`, every principal submatrix is PSD, so `A_hat>=0`.

Suppose `A_hat` were singular. Then there would exist nonzero `v` on the deleted-coordinate complement such that

`v^T A_hat v=0`.

Lift `v` to `u in R^m` by inserting

`u_a=0`.

Then

`u^T A u = v^T A_hat v =0`.

For a PSD matrix, zero quadratic energy implies membership in the kernel, hence

`u in ker(A)=span{z}`.

So `u=t z` for some scalar `t`. But `u_a=0` and `z_a>0`, hence `t=0`, contradicting `u!=0`.

Therefore `A_hat` is positive definite.

QED.

### Consequence

Every active coordinate is a legal anchor after T-P5-179 canonical support descent. There is no pivot search for a nonsingular principal minor: **all one-coordinate deletions work** in the strict positive corank-one branch.

## 4. T180-C — canonical anchor-gauge range solve

Delete active column `a` from `B` and call the result

`B_hat in R^{p x (m-1)}`.

Because `A_hat` is SPD, solve

`A_hat X_hat = B_hat^T`.

Embed `X_hat` into `X in R^{m x p}` by inserting the zero row

`X[a,:]=0`.

### Theorem

The embedded matrix satisfies the full range equation

`A X = B^T`.

### Proof

By construction, every row of

`R := A X-B^T`

except possibly row `a` is zero.

Also

`z^T R = z^T A X-z^T B^T = 0-(Bz)^T=0`.

Since only row `a` may be nonzero,

`z^T R = z_a R[a,:]`.

Because `z_a>0`, this forces

`R[a,:]=0`.

Hence `AX=B^T` exactly.

QED.

This gives a canonical **anchor gauge** for the range solve: set one active row of `X` to zero and solve only an ordinary SPD system.

## 5. T180-D — exact completed square and reduced copositivity

Define

`H := C-BX`.

Since `AX=B^T`,

`BX = X^T A X`

is symmetric. For arbitrary `u in R^m` and `y in R^p`,

`Phi(u,y)`

`= u^T A u + 2 y^T B u + y^T C y`

`= (u+Xy)^T A (u+Xy) + y^T H y`.

Therefore:

### Theorem `corankOneCriticalBlock_iff_reducedCopositive`

Under the setup above,

`Phi(u,y)>=0` for every `u in R^m`, `y>=0`

iff

`y^T H y>=0` for every `y>=0`.

That is,

**the mixed critical block is nonnegative on `R^m x R_+^p` iff `H` is copositive.**

### Necessity

For any `y>=0`, choose

`u=-Xy`.

Then the PSD square vanishes and

`Phi(-Xy,y)=y^T H y`.

### Sufficiency

The first term in the completed square is nonnegative because `A>=0`, and the second is nonnegative by copositivity of `H`.

QED.

This recovers T-P5-178 in the corank-one branch but eliminates its separate hidden-kernel/range-solve obligation.

## 6. T180-E — division-free rational packet

Because the anchor solve uses only the SPD matrix `A_hat`,

`X_hat = A_hat^{-1} B_hat^T`.

Hence

`H = C-B_hat A_hat^{-1} B_hat^T`.

Let

`delta_a := det(A_hat)>0`.

Using

`A_hat^{-1}=adj(A_hat)/delta_a`,

define the scaled Schur matrix

**`Q_a := delta_a C - B_hat adj(A_hat) B_hat^T`.**

Then

`Q_a = delta_a H`.

Since `delta_a>0`,

**`H copositive iff Q_a copositive`.**

This is the preferred exact packet for rational source data:

1. verify `A>=0`, `rank(A)=m-1`, `Az=0`, `z>0`;
2. verify `Bz=0`;
3. choose any anchor `a`;
4. verify `delta_a=det(A_hat)>0`;
5. compute integer/rational cofactors `adj(A_hat)`;
6. construct `Q_a` with multiplication and addition only;
7. dispatch `Q_a` to the existing low-dimensional/Z-matrix/negative-graph/general copositivity machinery.

No inverse, pseudoinverse, square root, eigenvector normalization, or floating tolerance is part of the mathematical certificate.

## 7. T180-F — anchor invariance

The reduction does not depend on which positive active coordinate is deleted.

Let `a` and `b` be two anchors. Let `X_a`, `X_b` be the corresponding gauge solves.

Both satisfy

`AX_a=B^T`, `AX_b=B^T`.

Thus every column of

`X_a-X_b`

lies in `ker(A)=span{z}`. Therefore there exists a row vector `gamma^T` such that

`X_a-X_b=z gamma^T`.

Since `Bz=0`,

`B X_a-B X_b = Bz gamma^T=0`.

Hence

**`H_a=H_b`.**

Consequently

`Q_a/delta_a = Q_b/delta_b = H`.

Because every `delta_a>0`, all anchor packets have exactly the same copositivity sign.

This is useful operationally: a producer may choose the anchor with the cheapest exact coefficients without changing the theorem being certified.

## 8. T180-G — one critical row collapses to one determinant

Suppose `p=1`. Write the unique critical row as `b^T` and the inactive scalar as `c`.

Delete anchor `a` and define

`b_hat` accordingly. Then `Q_a` is the scalar

`q_a = delta_a c - b_hat^T adj(A_hat) b_hat`.

The mixed critical block is locally nonnegative iff

**`q_a>=0`.**

Equivalently, let

`K_hat_a = [[A_hat, b_hat], [b_hat^T, c]]`.

By the bordered determinant identity,

**`det(K_hat_a)=q_a`.**

Therefore:

> at a strict positive corank-one active zero contact with exactly one zero-residual inactive row, the entire second-order T-P5-178 closure is one ordinary principal bordered determinant sign.

No copositivity search remains.

### Stronger observation

In the one-row case, `q_a>=0` actually makes the full critical block PSD, not merely mixed-cone nonnegative, because its completed square has a scalar nonnegative Schur remainder.

## 9. Exact rational regression A — sharp one-row boundary

`b=(2,-2)`,

`b^T z=0`.

Choose anchor `a=1`. Then

`A_hat=[1]`, `delta=1`, `b_hat=[-2]`.

### Boundary value `c=4`

The scalar packet is

`q_a = 1*4-(-2)^2=0`.

Thus the critical block is exactly on the PSD/copositive boundary. Indeed

`[[1,-1,2],[-1,1,-2],[2,-2,4]]`

`(1,-1,2)^T(1,-1,2)`.

### Failure value `c=3`

`q_a=3-4=-1<0`.

`X=(0,-2)^T`,

`Phi(u,1)=-1`.

Thus the determinant failure produces an explicit critical-cone counterexample, not merely a suspicious matrix minor.

## 11. Higher-corank obstruction — why the theorem must not be generalized

Corank one is essential.

Take

`v=(1,-1,0)`,

`A=v v^T=[[1,-1,0],[-1,1,0],[0,0,0]]`.

Then `A>=0` but `rank(A)=1`, so `corank(A)=2`.

The strict positive vector

`z=(1,1,1)`

lies in `ker(A)`.

Take

`b=(1,0,-1)`.

Then

`b^T z=0`,

so the ordinary contact residual vanishes. However

`range(A)=span{(1,-1,0)}`,

and `b` is not in that range.

There is a hidden kernel vector

`n=(1,1,-2)`

with

`A n=0`, `b^T n=3`.

For the one-row critical block with `c=0`, choose inactive `y=1` and active direction `u=t n`. Then

`Phi(tn,1)=2 t b^T n=6t`,

which tends to `-infinity` as `t->-infinity`.

Thus:

**`b^T z=0` does not imply range compatibility when the active corank exceeds one.**

The higher-corank branch must continue to use T-P5-178's full-kernel/range criterion. This is a decisive fail-closed boundary, not a checker implementation detail.

## 12. Support/anchor boundary

Strict positivity of the canonical support is also essential for the claim that every anchor deletion is SPD.

For example,

`A=diag(0,1)`, `z=(1,0)`.

The contact has a zero declared coordinate. If one incorrectly keeps both coordinates active and deletes anchor `a=2`, the remaining principal block is `[0]`, which is singular.

T-P5-179 provides the correct cure: first descend to the true positive support. After that descent, every retained active coordinate has positive `z_a`, and the anchor theorem applies.

## 15. Obstructions and failure modes locked down

### Boundary A — higher corank

Do not replace the T-P5-178 full-kernel test by the single equation `Bz=0` unless `corank(A)=1` is certified. The explicit rank-one `3x3` example above gives an unbounded hidden-kernel shear.

### Boundary B — noncanonical support

Do not choose an anchor on a declared active coordinate where the contact is actually zero. Canonicalize the support first via T-P5-179.

### Boundary C — multiple critical rows still require copositivity

For `p>1`, the reduced `H`/`Q_a` need only be copositive, not PSD. A PSD test remains only a sufficient shortcut outside special sign corridors. Do not silently strengthen the theorem.

### Boundary D — local contact is not global P5 closure

The theorem decides the T-P5-178 local critical block at one returned contact. Global support coverage and actual source identity remain separate obligations.
