## 1. Endpoint critical-block setup

Let the endpoint quadratic on the T-P5-210 critical variables be

`H = [[A, R^T], [R, C]]`,

where the variables are `(u, eta)` with

`u in R^m`,

`eta in R_+^p`.

The signed variable `u` is the tangent on the strictly positive active support; the one-sided variable `eta` consists only of the inactive rows whose first-order endpoint residual is zero.

Assume

1. `A=A^T >= 0`;
2. `rank(A)=m-1`;
3. `ker(A)=span{z}` with `z>0` coordinatewise;
4. `R z=0`.

The fourth condition is exactly the zero-residual condition needed by T-P5-180. Since `range(A)=z^perp`, it implies

`range(R^T) subseteq range(A)`.

Hence choose any exact range solve

`A X = R^T`.

T-P5-180 shows that a canonical rational `X` can be obtained by deleting any positive active anchor coordinate and solving the resulting SPD principal system. Define the Schur remainder

`K := C-RX`.

Then the exact completed-square identity is

**`(u,eta)^T H (u,eta) = (u+X eta)^T A (u+X eta) + eta^T K eta`.**

The matrix `K` is independent of the gauge change

`X -> X+z gamma^T`,

because `Rz=0`.

For the new scalarization branch assume in addition

5. `K=K^T >=0`;
6. `rank(K)=p-1`;
7. `ker(K)=span{xi}` for some `xi>0`.

Equivalently, once PSD and corank one have been certified,

**`adj(K)` is entrywise strictly positive.**

Indeed a PSD corank-one matrix has

`adj(K)=kappa xi xi^T`

for some `kappa>0`; therefore `xi` can be chosen strictly positive iff every entry of `adj(K)` is positive.

## 3. Pull the debit quadratic onto the zero sheet

Partition the T-P5-210 debit direction as

`Q = [[P, T^T], [T, U]]`,

with `P=P^T`, `U=U^T`.

Define

`a := z^T P z`,

`g := T z-X^T P z`,

and the symmetric pulled second-order matrix

`G := U + X^T P X - T X - X^T T^T`.

A direct expansion gives, for arbitrary `alpha` and `eta`,

`(alpha z-X eta, eta)^T Q (alpha z-X eta, eta)`

`= a alpha^2 + 2 alpha g^T eta + eta^T G eta`.

Restricting further to the reduced kernel ray `eta=beta xi`, define

`b := xi^T g`,

`c := xi^T G xi`.

Then on every endpoint zero-energy critical tangent,

**`v(alpha,beta)^T Q v(alpha,beta) = a alpha^2+2 b alpha beta+c beta^2`.**

This is exact. No inequality has been introduced.

## 14. Boundaries and exact routing

### Boundary A — reduced Schur block positive definite

If `K>0`, there is no inactive zero-energy direction. In the common-zero branch `a=0`, the corank-one active scaling direction has zero debit, so this T-P5-211 route produces no second-order witness.

### Boundary B — reduced Schur block has corank greater than one

Then

`adj(K)=0`.

The two-scalar packet loses all information. This is not evidence of safety. Route to the existing higher-corank kernel machinery from T-P5-174 / T-P5-178 / T-P5-182.

### Boundary C — reduced kernel is not a strict positive ray

For PSD corank-one `K`, if its kernel generator has mixed signs, there is no nonzero `eta>=0` on that kernel, so the inactive zero sheet disappears.

If the kernel generator is nonnegative but has zero coordinates, descend to its true support first, exactly in the spirit of T-P5-179, and apply the theorem there if the reduced principal block remains corank one.

### Boundary D — active block has higher corank

Then `Rz=0` does not imply full range compatibility. Do not use the T-P5-180 anchor solve. Route to the higher-corank range / kernel basis machinery.

### Boundary E — active contact is not strict positive on its declared support

Then the active tangent is not all of `R^m`. Canonically support-descend before using this theorem.

### Boundary F — endpoint Schur remainder is merely copositive, not PSD

A copositive `K` can have nonnegative zero-energy points without satisfying `Keta=0`. The completed-square nullspace argument used here is then invalid. This branch deliberately requires PSD `K`; generic copositive zero faces remain a separate nonlinear/contact obligation.

### Boundary G — do not omit dual criticality

`Ccrit>0` alone is insufficient. Regression B shows that `Bcrit>0` can remove the entire inactive zero ray from the T-P5-210 double-critical cone.

### Boundary H — local endpoint theorem only

The result proves immediate failure beyond a candidate endpoint once its hypotheses hold. It does not prove that the candidate endpoint itself is globally safe over every support, cell, selector cone, or physical trajectory.
