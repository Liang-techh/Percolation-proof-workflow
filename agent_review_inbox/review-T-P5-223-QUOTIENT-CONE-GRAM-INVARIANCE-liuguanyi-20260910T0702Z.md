# T-P5-223 — quotient-cone Gram representation invariance

## 0. Verdict and seam closed

**CONDITIONAL_PASS_MATHEMATICAL_CHILD / pending source binding.**

T-P5-221 proves that endpoint/storage bilinear pairings can be transported across unrelated PD-prefix charts by full-coordinate reconstruction numerators. T-P5-222 then proves that face-dependent endpoint lifts are physically meaningful only after their lift gauge is radical for the endpoint debit form.

Once both gates hold, one more representation issue remains: the same physical endpoint zero cone may be generated by several different lifted atom packets, often with redundant columns. A checker/producer must know whether it may eliminate such columns, merge chart packets, or replace one generator family by another without changing the endpoint-debit question.

This child gives the exact theorem.

Let `Q=Q^T` be the endpoint debit form on an ambient vector space `Y`, let `N` be an admissible lift-gauge subspace, and assume the T-P5-222 radical condition on the subspace actually used below. If `W=[w_1 ... w_r]` is a lifted generator matrix, then the pulled Gram matrix

`D_W := W^T Q W`

is not merely a coordinate artifact: it **factors through the physical quotient cone**

`C_W := { [W a] in Y/N : a >= 0 }`.

In particular:

1. any coefficient ambiguity `W r in N` lies in `ker(D_W)`;
2. if two packets are related modulo gauge by an exact nonnegative transport `W = Wtilde T + G A`, then

   **`D_W = T^T D_Wtilde T`;**

3. if the transports exist both ways, the two packets have exactly the same attainable debit values and the same existence/nonexistence of a positive debit witness;
4. inside a fixed storage-zero compatibility clique, a generator that is conically redundant modulo endpoint gauge may be deleted with no loss;
5. **outside a fixed compatibility clique this pruning is unsound**: endpoint-cone redundancy alone does not preserve the storage-zero admissibility relation used by T-P5-215.

The last point is a real mathematical boundary, not provenance bookkeeping. An exact rational counterexample is given below.

## 1. Setup: quotient debit and lifted generator packets

Let `Y = R^m`. Let

`Q = Q^T in R^{m x m}`

be the symmetric endpoint/debit matrix. Let `N subset Y` be a linear gauge subspace. Write

`pi : Y -> Y/N`

for the quotient map.

For a finite lifted endpoint packet, let

`W = [w_1 ... w_r] in R^{m x r}`.

The coefficient orthant produces the physical quotient cone

`C_W = pi(W R_+^r)`.

Let `G` be any matrix whose columns span the gauge directions actually allowed for this packet. T-P5-222 gives a convenient exact sufficient-and-necessary restricted radical gate on

`U = span(W,G)`:

`G^T Q W = 0`,

`G^T Q G = 0`.

Equivalently every gauge vector in `span(G)` pairs to zero under `Q` with every vector in `U`.

Define the pulled Gram matrix

**`D_W := W^T Q W`.**

For coefficients `a,b`,

`a^T D_W b = (W a)^T Q (W b)`.

The purpose of the following lemmas is to show exactly which changes of generator representation preserve this scalar after quotienting by the face-lift gauge.

## 2. T223-A — coefficient ambiguity is killed by the Gram matrix

### Theorem A — quotient-kernel annihilation

Assume the restricted radical gate for `span(W,G)`. If

`W r = G s`

for some coefficient vector `r` and some gauge coefficient vector `s`, then

**`D_W r = 0`.**

Consequently, for every `a,b` with `W(a-b) in N`,

**`D_W a = D_W b`,**

and therefore

`a^T D_W a = b^T D_W b`.

More generally, for every third coefficient vector `c`,

`a^T D_W c = b^T D_W c`.

### Proof

From `Wr=Gs`,

`D_W r = W^T Q W r = W^T Q G s`.

By symmetry of `Q` and `G^T Q W=0`,

`W^T Q G = 0`.

Hence `D_W r=0`.

Taking `r=a-b` gives the remaining claims immediately. QED.

### Interpretation

The coefficient-level nullspace relevant to debit is at least

`ker(pi o W)`.

Thus any decomposition ambiguity that represents the same quotient endpoint class is automatically invisible to the pulled Gram form. No pseudoinverse, quotient basis, or canonical representative is required.

This is stronger than merely saying that the **quadratic** value is independent of representatives: the entire Gram action is constant on coefficient classes modulo `ker(pi o W)`, so all cross-debit pairings descend as well.

## 3. T223-B — one-way nonnegative transport gives exact Gram congruence

Let a second lifted packet be

`Wtilde in R^{m x s}`.

Assume a common gauge generator matrix `G` and that the restricted radical condition holds on

`span(W,Wtilde,G)`.

Suppose there exist matrices

`T in R^{s x r}` with `T >= 0` entrywise,

and an arbitrary real matrix `A`, such that

**`W = Wtilde T + G A`.**

This is an exact checker-friendly statement that every generator of `W` lies in the quotient cone generated by `Wtilde`.

### Theorem B — nonnegative transport congruence

Under the above assumptions,

**`D_W = T^T D_Wtilde T`.**

Hence for every `a>=0`, if `b:=Ta>=0`, then

**`a^T D_W a = b^T D_Wtilde b`.**

The same holds bilinearly for two coefficient vectors:

`a^T D_W c = (Ta)^T D_Wtilde (Tc)`.

### Proof

Expand using `W=Wtilde T+GA`:

`D_W`

`= W^T Q W`

`= (Wtilde T+GA)^T Q (Wtilde T+GA)`

`= T^T Wtilde^T Q Wtilde T`

`  + T^T Wtilde^T Q G A`

`  + A^T G^T Q Wtilde T`

`  + A^T G^T Q G A`.

All three terms involving `G` vanish by the restricted radical gate. Therefore

`D_W=T^T D_Wtilde T`.

Because `T>=0`, `a>=0` implies `Ta>=0`. QED.

### Corollary B1 — one-way implication for cone properties

If `D_Wtilde` is copositive, then `D_W` is copositive.

If there exists `a>=0` with `a^T D_W a>0`, then there exists `b>=0` with `b^T D_Wtilde b>0`.

Similarly, if `D_Wtilde` is nonpositive on its coefficient orthant, then `D_W` is nonpositive on its coefficient orthant.

The direction of implication follows the quotient-cone inclusion. No reverse conclusion is allowed without a reverse nonnegative transport.

## 4. T223-C — two-way transport makes debit questions representation invariant

Assume in addition that there exist

`S in R_+^{r x s}`

and an arbitrary matrix `B` such that

**`Wtilde = W S + G B`.**

Then the two quotient cones are equal:

`C_W = C_Wtilde`.

### Theorem C — quotient-cone representation invariance

Under the two transports,

`D_W = T^T D_Wtilde T`,

`D_Wtilde = S^T D_W S`.

Consequently the sets of physical debit values agree exactly:

**`{a^T D_W a : a>=0} = {b^T D_Wtilde b : b>=0}`.**

In particular the following are representation invariant:

- existence of a positive debit witness;
- existence of a negative debit witness;
- nonnegativity/copotivity of the endpoint Gram form on the represented quotient cone;
- nonpositivity of the endpoint debit on that cone;
- zero-debit of every represented physical endpoint class.

### Proof

The two congruences follow from Theorem B in both directions. For any `a>=0`, `b=Ta>=0` attains the same value in the second packet. Conversely any `b>=0` maps to `a=Sb>=0` with the same value in the first packet. Therefore the two value sets are equal. QED.

### Important detail

This does **not** assert `ST=I` or `TS=I`. Redundant generator packets rarely admit inverse linear coordinate maps. Only equality of the **quotient cones** and equality of the induced quadratic scalar are needed.

This is why nonnegative transports plus gauge residuals are a better exact interface than attempting to construct a quotient-space basis or a pseudoinverse.

## 5. T223-D — exact generator deletion inside a compatible zero face

Now reconnect the endpoint packet to the storage-zero geometry used by T-P5-215/T-P5-216.

Let `K` be the symmetric copositive storage matrix, and let

`xi_1,...,xi_r >= 0`

be storage-zero atoms:

`xi_i^T K xi_i = 0`.

Assume an index set `C` is a **compatibility clique**:

`xi_i^T K xi_j = 0`

for every `i,j in C`.

Then every nonnegative combination of atoms in `C` is again a storage zero, because

`q_K(sum_i a_i xi_i)`

`= sum_i a_i^2 q_K(xi_i) + 2 sum_{i<j} a_i a_j xi_i^T K xi_j`

`=0`.

Let `W_C` be the corresponding lifted endpoint generators after T-P5-221/T-P5-222 transport.

Suppose one column `w_j`, `j in C`, satisfies an exact quotient-conic redundancy relation

**`w_j = W_{C\{j}} t + G s`, with `t>=0`.**

### Theorem D — compatible-face generator pruning

Deleting generator `j` does not change the physical endpoint quotient cone generated by the clique, does not change the set of endpoint debit values attained by storage-zero vectors generated by that clique, and therefore does not change whether that zero face contains a positive endpoint-debit witness.

### Proof

The reduced packet is trivially a subpacket of the old packet, so its quotient cone is contained in the old quotient cone.

Conversely take any old coefficient vector `a>=0`. Replace the amount `a_j w_j` by

`a_j W_{C\{j}} t + a_j Gs`.

The new reduced coefficients are

`a'_i = a_i + a_j t_i >=0`.

Thus the quotient endpoint class is unchanged. Because all replacement atoms stay in the same compatibility clique, the corresponding storage vector remains in the same zero cone. T-P5-222 radicality then preserves every endpoint debit pairing. Hence the debit scalar is unchanged.

Equivalently this is Theorem C with the obvious selection transport in one direction and the conic-replacement transport in the other. QED.

### Checker-friendly deletion certificate

For rational packet data, a producer only needs to emit:

- the deleted column index `j`;
- a nonnegative rational vector `t`;
- a free rational gauge coefficient vector `s`;
- the exact equality `w_j-W_{-j}t=Gs`;
- confirmation that all replacement atoms lie in the same already-established compatibility clique.

No quotient basis is necessary.

For rational matrices, feasibility of this linear equality/inequality system has a rational witness whenever it has a real witness, because it is a rational polyhedron. Thus the deletion certificate can remain exact-rational.

## 6. T223-E — why endpoint-cone redundancy alone is NOT enough

The fixed-clique hypothesis in Theorem D is essential.

A lifted endpoint generator may be conically redundant in `Y/N` while the storage atoms used to reproduce it are not jointly compatible. In that case deleting the original atom can destroy a legitimate T-P5-215 witness.

### Exact rational counterexample

Take three storage atoms in coefficient coordinates and the copositive matrix

`K = [[0,1,0],`

`     [1,0,0],`

`     [0,0,0]]`.

For `x>=0`,

`x^T K x = 2 x_1 x_2 >=0`,

so `K` is copositive.

Let

`xi_1=e_1`, `xi_2=e_2`, `xi_3=e_3`.

Each is a storage zero. However

`xi_1^T K xi_2 = 1 >0`,

so atoms 1 and 2 are **not compatible** and their positive combination is not a storage zero.

Now let the endpoint space be `Y=R^2`, with no gauge (`N=0`), and set

`w_1=(1,0)`,

`w_2=(0,1)`,

`w_3=(1,1)=w_1+w_2`.

Thus endpoint generator 3 is perfectly conically redundant.

Choose endpoint debit form

`Q = [[0,1],`

`     [1,0]]`.

Then

`q_Q(w_1)=0`,

`q_Q(w_2)=0`,

but

**`q_Q(w_3)=2>0`.**

Therefore atom 3 is a valid one-atom positive-debit witness. If one deletes it merely because `w_3=w_1+w_2`, the only apparent replacement uses atoms 1 and 2 together; that pair is forbidden by the storage-zero compatibility gate. The remaining legal one-atom endpoints both have zero debit, so a naive endpoint-only pruning pass would produce a false negative.

### Boundary conclusion

**Endpoint quotient-cone redundancy is safe for pruning only after the replacement has been localized to the same storage-zero compatibility cone/face.**

The endpoint layer cannot erase the compatibility graph supplied by the storage layer.

This is a cross-layer semantic requirement and should be part of any producer interface that performs atom compression.

## 7. Exact rational regression with a genuine lift gauge

A second regression checks the positive theorem rather than only the boundary.

Let `Y=R^3`, gauge

`N=span(e_3)`,

and

`Q = [[0,1,0],`

`     [1,0,0],`

`     [0,0,0]]`.

Then `N subset ker(Q)`, so the global T-P5-222 radical gate holds.

Use reduced packet

`Wtilde=[e_1,e_2]`

and redundant packet

`W=[e_1,e_2,e_1+e_2+e_3]`.

The third column differs from `e_1+e_2` only by gauge.

Take

`T = [[1,0,1],`

`     [0,1,1]]`.

Then

`W = Wtilde T + e_3 [0,0,1]`.

The reduced Gram matrix is

`D_Wtilde = [[0,1],`

`            [1,0]]`.

The full Gram matrix is

`D_W = [[0,1,1],`

`       [1,0,1],`

`       [1,1,2]]`.

Direct multiplication gives exactly

**`D_W = T^T D_Wtilde T`.**

For the redundant coefficient vector `a=e_3`,

`a^T D_W a = 2`.

Its reduced image is

`Ta=(1,1)`,

and

`(Ta)^T D_Wtilde (Ta)=2`.

So a positive debit witness survives deletion exactly, even though the old and new coefficient dimensions differ and the deleted column carries a nonzero face-lift gauge component.

## 8. Interaction with T-P5-221 fraction-free chart numerators

The theorem above is written in physical lifted vectors, but T-P5-221 stores chart atoms fraction-free.

For chart/face label `(a,f)`, T-P5-222 defines a tangent reconstruction numerator

`J_{a,f}=L_f M_a`

with positive chart denominator `d_a`.

A physical lifted generator has form

`w_i = J_i lambda_i / d_i`.

A quotient-conic relation among heterogeneous chart atoms may therefore be checked without division by multiplying by a common positive denominator.

For example, a relation

`w_j = sum_i t_i w_i + Gs`, `t_i>=0`

is equivalent, after multiplying by any positive common denominator `D` divisible by the chart denominators, to the exact numerator identity

`(D/d_j) J_j lambda_j`

`= sum_i t_i (D/d_i) J_i lambda_i + D Gs`.

If the coefficients are rational, denominators can be absorbed into nonnegative rational transport coefficients. Thus the T223 pruning/transport gate is compatible with T-P5-221's fraction-free design and does not require reconstructing floating physical vectors.

The pulled cross-chart debit itself remains

`Qhat_{ij}=J_i^T Q J_j`,

with the corresponding positive denominator product `d_i d_j`. All sign/zero statements used in the present theorem are therefore invariant under the positive projective rescalings already identified in T-P5-220/T-P5-221.
