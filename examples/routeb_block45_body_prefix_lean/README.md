# Block-(4,5) single-body prefix semantic leaf

This sidecar instantiates the generic body semantics on the two zero-based
body slots corresponding to Julia links 4 and 5. It proves the link-4/joint-5
inactive cutoff, the link-5/joint-5 active translational and angular formulas,
the midpoint COM interface, and the link-5 mass-to-`linkMass` interface.

The frame prefix is abstract and real-valued; no DH matrix entries are
unfolded, and Julia `Float64` or full deployed mass equality is not claimed.
