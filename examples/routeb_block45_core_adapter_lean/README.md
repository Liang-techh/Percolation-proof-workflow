# Block-(4,5) minimal-core source adapter

This sidecar connects the Mathlib-only body semantic core to the source-bound
Route-B frame/origin/axis slots. It proves only the four narrow block-(4,5)
interfaces needed before mass assembly: link-4 COM, link-4/joint-5 inactivity,
and link-5/joint-5 translational and angular active formulas.

It deliberately does not expand the mass matrix or claim Julia `Float64`
equality.
