# Route-B concrete frame-prefix homogeneous adapter

This narrow sidecar proves the next source-binding interface after the
individual DH-step theorem: the concrete `routeBFrameSlot` is the generic
`homogeneousPrefix` of the extracted rotation and translation blocks.

The proof keeps the six DH matrices opaque at the prefix level. It does not
assert Julia `Float64` equality, Fourier CSV equality, or the full mass
identity.
