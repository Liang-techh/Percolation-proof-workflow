# Failed derivations and audit repair history

The successful final audit was **not the first attempt**. This record describes
the provisional expressions and failures visible in this task's tool history.
The overwritten initial script versions were not saved as separate snapshots;
those snapshots are unavailable. This is a retrospective transcription, not a
claim that original failed-output files or versioned drafts were preserved.
The conversation's `apply_patch` and `exec_command` outputs are the evidence for
the edits and exit statuses. No stable external URL to those tool events is
available here.

Notation follows DERIVATION.md: s=q2+q3, x=q4, y=q5; constants b,j,J,H,A,k are
defined there. The failures were exact coefficient comparisons, not numerical
sampling discrepancies.

## First stopping point: M41

The provisional expression was

```
F_old = A cos s + sin y [cos x (H+j sin s+k sin s cos y)
                       +b cos s sin x].
```

The audit exited with `AssertionError: ('mass formula mismatch', (3, 0))`.
Indices in that error are zero-based: this is M41. The coefficients b and j
in the two indicated terms had been interchanged. The corrected expression is

```
F = A cos s + sin y [cos x (H+b sin s+k sin s cos y)
                   +j cos s sin x].
```

The assertion was also enhanced to print the exact residual coefficient map.

## Second stopping point: M61, with linked provisional spin signs

After that repair, the next run exited with
`AssertionError: ('mass formula mismatch', (5, 0), ...)`, i.e. M61.
The provisional orientation factor was

```
N_old = cos s cos y + sin s cos x sin y.
```

The residual `M61_source-J*N_old` contained eight real Fourier modes. At nu1=nu6=0,
the representative positive-s modes were

```
(nu2,nu3,nu4,nu5) = (1,1,-1,-1): -1/240
                     (1,1,-1, 1):  1/240
                     (1,1, 1,-1): -1/240
                     (1,1, 1, 1):  1/240
```

and the other four were their conjugates. The correction is

```
N = cos s cos y - sin s cos x sin y.
```

The same patch corrected the provisional v1*v6 coefficients in the compact
Coriolis spin formulas:

| Coefficient | Provisional, incorrect | Corrected and audited |
|---|---|---|
| C4, v1*v6 | +J sin s sin x sin y | -J sin s sin x sin y |
| C5, v1*v6 | J(cos s sin y-sin s cos x cos y) | J(cos s sin y+sin s cos x cos y) |

Other displayed spin coefficients were unchanged. **No separate failed C4/C5
assertion was observed**: both failed runs stopped earlier at the mass-formula
checks. The provisional spin expressions were corrected before execution
reached their assertions. It would be inaccurate to claim that the original
spin expressions passed, or that an independently saved failed spin test exists.
