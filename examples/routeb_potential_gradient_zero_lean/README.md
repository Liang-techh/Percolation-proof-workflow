# Route-B origin Fourier-gradient leaf

This sidecar proves that the exact 17-row Fourier potential payload has zero
coordinate gradient at the all-zero configuration.  The proof is purely
algebraic: every row phase is zero there, hence every sine factor vanishes.

The theorem is useful for the equilibrium-floor frontier, but it does not bind
the deployed Julia potential, central finite differences, `H0`, or `G0`.
Those source and Float64 obligations remain open and no registry admission is
made.
