# Route-B two-body mass sum

This leaf closes the finite block-(4,5) source/frame mass-sum interface. It
defines the sum of body-3 and body-4 contract contributions and proves its
entrywise equality between the source slot contract and the frame contract,
reusing the verified single-body leaves. It remains a semantic candidate only:
the six-body evaluator, regularizer, Float64 enclosure, and comparator are open.
